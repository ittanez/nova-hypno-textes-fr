**Statut** : Draft (à importer dans Google Ads)

**Lancement prévu** : 2026-09-18

**Budget quotidien** : 3,30 € / jour (test côte à côte avec "Anxiete Paris Search 2026")

## Structure

- **Landing page** : `https://novahypnose.fr/prise-de-parole-hypnose-paris.html`
- **Localisation** : Paris + Île-de-France + France (pour visio)
- **Langue** : Français
- **Stratégie d'enchères** : Maximize conversions (comme Anxiete Paris)

## Groupes d'annonces

1. **Prise de parole — Urgent** (CPC attendu : 1,00–1,80 €)
   - Mots-clés très ciblés sur la peur immédiate
   - "peur de parler en public", "anxiete prise de parole", etc.

2. **Prise de parole — Large** (CPC attendu : 0,70–1,30 €)
   - Variantes plus larges
   - "prise de parole en public", "hypnose prise de parole", etc.

3. **Situations précises** (CPC attendu : 1,20–2,20 €)
   - Très ciblé sur contextes spécifiques
   - "peur oral reunion", "stress presentation travail", "phobie pitch", etc.
